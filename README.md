# Контест «Предсказание цен на недвижимость»

Решение находится в ноутбуке `solution.ipynb`. После запуска рядом с ним появляется `submission.csv`.

## Запуск

Положите `train.csv`, `test.csv` и `sample_submission.csv` в папку `data/`, затем выполните:

```bash
pip install -r requirements.txt
jupyter nbconvert --to notebook --execute --inplace solution.ipynb
```

Весь ноутбук выполняется примерно за 5 минут на 20 потоках.

## Подход

- Тренд цен вынесен из модели и продлён на 2013 год с затуханием (φ = 0.8), затем скорректирован по публичному лидерборду: поправка растёт от +2% в январе до +12% в декабре 2013 года.
- Строки с ценой-заглушкой 1 000 000 (около 4%) убраны из обучения.
- Цель модели: лог цены за м² за вычетом уровня улицы.
- Прогноз: среднее LightGBM и CatBoost с функцией потерь L1.

## Качество

| Проверка | MAE, руб. |
|---|---|
| Кросс-валидация по месяцам, смесь моделей | ≈ 530 000 |
| Бэктест на будущее, только LightGBM | ≈ 580 000–590 000 |
| Public, первая посылка без поправки на 2013 год | 723 751 |
| Public, лучшая проба с нарастающей поправкой | 624 593 |

Около 170 000 руб. в этих значениях дают заглушки, которые предсказать нельзя. Бэктест оказался слишком оптимистичным: 2013 год в train не представлен, а цены в тесте выше, чем в train.
